# Claim-to-code, data, and verification boundaries

All files in this branch support the **Kalyna** manuscript, not WARP or unrelated projects. This page is a reviewer navigation aid.

**Functional compiler.** `src/kalyna_oracle/compiler.py` gives the reversible X/CNOT/CCNOT tape, full Kalyna key schedule and encryption. `validation/run_full_oracle_certificate.py` compares official plus 10 seeded random cases against the pinned independent C reference; it checks all round keys, ciphertext, the correct historical-key phase mark, four wrong-key cases and clean reverse uncomputation. Original evidence: `evidence/npj_submission_v3/full_oracle_certificate_summary.json`. This is a sampled basis-state validation plus structural inverse proof, not exhaustive functional verification for all 2^k keys.

**Monomial-bank improvement.** `validation/optimized_oracle_experiment.py` replaces only the S-box synthesis while preserving the original remaining compiler. `validation/check_sbox_monomial_bank.py` checks each 8-bit truth table exhaustively under the implemented adapter and verifies local cleanup and inverse. The full modified cipher and historical-key oracle were certified for both h=3 and h=4 by https://github.com/Indranil872001/kalyna/actions/runs/44899708507 . Results are frozen in `evidence/npj_optimized_validation/verified_optimized_measurements.json`. S-box trade-off counts are in `evidence/npj_optimized_validation/sbox_tradeoff.csv`. The claimed improvements are *relative to the same authors' original shared-ANF design*, not a global optimality statement.

**Logical resources.** `validation/corrected_resource_counts.py` regenerates the reference 10/14-round counts. `validation/optimized_oracle_experiment.py` counts the actual optimized emitted tape. Seven T gates are attributed to each CCNOT-equivalent; no physical mapping, magic-state distillation or fault-tolerant depth is modeled. Complete phase-oracle dependency depth excludes the diffuser depth.

**Restricted-domain Grover.** `validation/reference_sparse_scan.c` and `validation/run_fullround_sparse.py` find marked keys by *full-round classical encryption*, with 8–20 variable master-key bits. `validation/run_finite_shot_recovery.py` then computes exact Grover amplitudes, 1024-shot sampling and confidence thresholds. These are not gate-level quantum executions of the multi-thousand-qubit oracle. Data in `evidence/npj_submission_v3/`.

**Wrong-key occupancy.** `validation/reference_oracle_multiplicity.c` and `validation/run_oracle_multiplicity.py` reproduce the original 128-trial truncated-ciphertext comparisons. `validation/reference_oracle_multiplicity_seeded.c` and `validation/seeded_occupancy_replicate.py` reproduce the two-seed 512-observation-per-setting experiment; CI run https://github.com/Indranil872001/kalyna/actions/runs/44899877953 , frozen 18-row data in `evidence/npj_optimized_validation/seeded_occupancy_512_summary.csv`. The full 9216-record archive is in the corresponding manuscript submission ZIP; `bash scripts/reproduce.sh full` regenerates it. The ideal-cipher binomial probabilities are model-based nominal reference values, not exact model-free significance results for the deterministic generated subspaces.

**Not present by design:** duplicate evidence v1/v2, retired workflows, legacy ProjectQ structural estimators, unrelated WARP work and generated compiler outputs. The original branch history is preserved.
